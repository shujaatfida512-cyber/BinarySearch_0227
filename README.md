# Binary Search — C++

A C++ implementation that first sorts an integer array and then performs **Binary Search** for user-provided values.

## Concepts
- Arrays
- Bubble Sort
- Binary Search
- Functions
- Loops and input validation
- Boolean search results

## How it works
1. Read the array values.
2. Sort the array.
3. Search for requested values using Binary Search.
4. Report whether each value is found.

## Purpose
This repository demonstrates how sorting and searching algorithms can be combined in a practical console program.
